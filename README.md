| Раздел | Функция / Шаг | Подробная инструкция, команды и параметры |
| :--- | :--- | :--- |
| **🛠 1. Установка** | **Ubuntu / Debian** | `sudo apt update && sudo apt install python3 python3-pip python3-pyqt6 libx11-dev` |
| **🛠 1. Установка** | **Arch Linux / Manjaro** | `sudo pacman -S python python-pip qt6-base` |
| **🛠 1. Установка** | **Fedora** | `sudo dnf install python3 python3-pip qt6-qtbase` |
| **🛠 1. Установка** | **Python-модули** | `pip install PyQt6 pyautogui pynput opencv-python Pillow` |
| **🚀 2. Запуск** | **Обычный старт** | `python3 autoclicker.py` |
| **🚀 2. Запуск** | **Обход Wayland** | Если клики не ловятся в Wayland: `sudo python3 autoclicker.py` либо сменить сеанс на **X11** |
| **📖 3. Точки (Координаты)** | **Добавление точки** | Нажать **`+ Точка (3с)`** $\rightarrow$ навести курсор на объект $\rightarrow$ подождать 3 секунды до автосохранения |
| **📖 3. Точки (Координаты)** | **Параметры клика** | В таблице настраиваются: `Delay` (задержка), `Button` (left/right/middle), `Type` (single/double/hold) |
| **🖼 3. Картинки** | **Поиск по скриншоту** | Нажать **`+ Картинка`** $\rightarrow$ загрузить кроп/скриншот нужной кнопки для точного автопоиска на экране |
| **⏺ 3. Макросы** | **Запись действий** | Нажать **`Запись макроса`** $\rightarrow$ выполнить действия мышкой $\rightarrow$ нажать **`Остановить запись`** |
| **🛡 3. Античит** | **Рандомизация** | **Разброс XY:** 3–5 px (смещение клика)<br>**Разброс времени:** 0.2–0.4 с (случайные паузы во избежание бана) |
| **⏱ 3. Остановка** | **Режимы завершения** | Доступны три варианта: **Бесконечно** (пока не нажмете стоп), **Циклы** (лимит повторов) или **Таймер** |
| **⚙️ 3. Профили и Хоткеи** | **Горячие клавиши** | Старт/Стоп по умолчанию на **F8** (можно переназначить кнопкой **`Назначить`**). Сохранение/загрузка в `.json` |
| **❓ 4. Проблемы** | **Хоткей не работает** | Ограничения графического сервера Wayland $\rightarrow$ запустите с `sudo` или перейдите в сеанс X11 |
| **❓ 4. Проблемы** | **Ошибка при поиске картинок** | Отсутствует зависимость OpenCV $\rightarrow$ переустановите через `pip install opencv-python` |
| **❓ 4. Проблемы** | **Клики летят мимо цели** | Слишком сильный рандом $\rightarrow$ уменьшите значения в поле **Разброс XY (px)** |
